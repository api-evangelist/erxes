# erxes

> Open-source Experience Operating System (XOS) that unifies marketing, sales, operations and support in one self-hostable platform, positioned as a replacement for HubSpot, Zendesk, Linear and Wix. The machine surface is a GraphQL Federation API served by an Apollo Router gateway; there is no REST API and no OpenAPI. erxes is AGPL-3.0 with a proprietary Enterprise Edition, and ships ~one release per merge day (3.0.79, 2026-08-13).

GENERATED by the API Evangelist enrichment pipeline on 2026-08-13. erxes serves no llms.txt of its own — /llms.txt returns the marketing SPA shell on erxes.io and 404 on www.erxes.io and docs.erxes.io.

## How to call it

- Endpoint: `POST <gateway>/graphql`
- SaaS gateway pattern: `https://<subdomain>.next.erxes.io/gateway/graphql`
- Self-hosted: Apollo Router on `:4000` in dev; nginx proxies `/gateway/` to `127.0.0.1:3300` in the published production layout
- Required headers: `Content-Type: application/json`, `Authorization: Bearer <accessToken>`, `erxes-subdomain: <subdomain>`
- `erxes-subdomain` must NOT be sent on OAuth token/refresh requests — the gateway infers the tenant from the host
- Auth: OAuth 2.0 Device Authorization Grant (RFC 8628). Confidential clients for the agent plugin, public clients for the CLI. Access token TTL 28800s; device code TTL 600s; refresh tokens rotate. Clients are created per tenant in Settings > OAuth Clients.
- GraphQL introspection is DISABLED on the gateway (`INTROSPECTION_DISABLED`)
- A GraphQL error can arrive with HTTP 200 — never treat the status code alone as success
- There is NO idempotency key. Retrying a mutation creates a duplicate record.

## Known gaps

- No OpenAPI, no AsyncAPI, no MCP server, no A2A agent card, no llms.txt, no /.well-known/ documents on any host
- GraphQL introspection disabled, so no live schema is fetchable
- No idempotency contract; no deprecation policy; no Sunset/Deprecation headers; no SLA
- No published prices on any paid tier; no published rate limits on the GraphQL gateway
- No published error reference or event catalog outside the source code
- The current first-party CLI is installable only from a moving git branch; `com.erxes:messenger-sdk` is documented as a Maven Central coordinate but is not published there
